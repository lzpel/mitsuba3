Prebuilt wheels for lzpel/mitsuba3

A PEP 503 package index for wheels of this fork, hosted on GitHub Releases. Dependencies such as drjit are still installed from PyPI.

uv

uv add mitsuba --index mitsuba-fork=https://lzpel.github.io/mitsuba3/simple/

or add this to pyproject.toml:

[[tool.uv.index]]
name = "mitsuba-fork"
url = "https://lzpel.github.io/mitsuba3/simple/"
explicit = true

[tool.uv.sources]
mitsuba = { index = "mitsuba-fork" }

One-off: uv pip install mitsuba --index https://lzpel.github.io/mitsuba3/simple/

pip

pip install mitsuba --extra-index-url https://lzpel.github.io/mitsuba3/simple/

Fork versions carry a local label (e.g. 3.9.1+lzpel.1) and sort above the PyPI release with the same version number.
